How to play
  • Tap colors to fill the glowing row, then press Check. Tap a filled hole to clear it (or to pick which hole the next color goes in).
  • For each guess you get clue pegs, in no particular order: a black peg for every color in the right spot, and a white peg for every right color in the wrong spot.
  • Crack the code within the rows on the board to win. Each color also has a letter, so you can tell them apart without relying on color.
  • 2 players: one player secretly sets the code, then hands the device to the code breaker.
  • Computer cracks your code: set a code and watch the computer work it out from the clues.
  • Keyboard: number keys or the color letters add a color, Backspace removes, Enter checks.

Cross Sums

0:00
How to play
  • Fill every white square with a digit from 1 to 9.
  • Each run of white squares adds up to its clue: the number below the diagonal is for the run going down, the number above it is for the run going across.
  • No digit may appear twice in the same run.
  • The panel above the keypad lists the digit sets that could make the selected run. Use Notes to pencil in candidates.
  • Keyboard: digits fill, arrows move, Backspace erases, N toggles notes.
